02 // The Solution 03 / 11

The Solution: An In-Browser Active Defense Agent

⚡ Zero-Distraction Squeeze Sidebar

Physically shrinks host page margin so users stay protected while maintaining 100% interactability with forms and buttons.

✂️ Interactive Snipping Tool

User drags a crosshair bounding box over suspicious forms or logos. Canvas crops the region and Gemini Vision evaluates fake brands.

🔍 10-Hop Redirect Traversal

Traces shortlinks (bit.ly, tinyurl) up to 10 HTTP HEAD hops deep to find the unmasked destination server before scanning.

🤖 Active Countermeasures

Scam-Baiter Bot wastes attacker bandwidth with 3 friction personas; Recovery Wizard provides an actionable 4-step checklist.

03 // Frontend Architecture 04 / 11

Innovation 1: On-Demand "Squeeze" Sidebar UI

Why the Squeeze Sidebar Model Wins
  • Zero Default Clutter: Zero UI injected until explicitly toggled via launcher pill or icon.
  • Physical Viewport Squeeze: html.shield-squeeze-active applies width: calc(100% - 420px) and margin-right: 420px.
  • 0.28s Smooth Cubic-Bezier Transition: No screen jarring or layout breakage.
  • Iframe Sandbox Security: Security panel is hosted in an isolated iframe, preventing malicious host JS from tampering with Shield.

05 // Threat Intelligence 06 / 11

Innovation 3: Quishing Defense & Typosquatting Engine

Quishing Matrix Decoder
  • Bitmap Decoding: Jimp extracts RGBA pixel array; jsQR decodes position patterns directly.
  • Redirect Hopping: Recursively unwraps shortlinks up to 10 hops to expose the real target.
  • Safety Precision: Legitimate support QR codes receive 0 / 100; fake KYC QR traps receive 98 / 100.
Brand Homoglyph Engine
  • The rn → m Vulnerability: www.rnicrosoft.com mimics Microsoft identically.
  • Substitution Engine: Normalizes rn → m, 0 → o, 1 → l, and Punycode (xn--).
  • Enforced Evidence Floor: Locks detected typosquatting domains at 98 / 100 (Critical Threat).
